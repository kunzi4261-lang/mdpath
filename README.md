# mdpath

移动了一张截图，README 里的图片就可能打不开。mdpath 会扫描指定目录下的 Markdown 文件，检查链接指向的本地文件或目录是否存在，并标出需要修改的文档和行号。

## 在自己的仓库里试一下

使用 Python 3.10 或更新版本，无需安装第三方包。在本项目根目录运行：

```sh
python mdpath.py .
```

把最后的点换成其他仓库的目录，就能检查那个仓库。扫描全程在本地运行。

```sh
python mdpath.py "../my-notes"
python mdpath.py "../my-notes" --json
```

例如，`README.md` 第 3 行引用了 `images/实验 1.png`。把图片改名为 `实验 2.png` 后再次检查，第一行会指出需要更新的位置：

```text
README.md:3: missing: images/实验 1.png
```

使用 `--json` 时，`files` 和 `links` 给出已检查的文件数和本地目标数。`broken` 中的每条记录都包含文档路径、行号、目标和原因，读取失败等问题记录在 `errors` 中。

## 哪些链接会被检查

| Markdown 写法 | 检查方式 |
| --- | --- |
| `[使用说明](docs/guide.md)` | 从当前文档所在目录查找文件 |
| `![实验结果](<images/实验 1.png>)` | 检查带中文、空格的图片路径 |
| `[数据](../data/)` | 检查当前文档上一级的目录 |
| `[首页](/README.md)` | 从本次指定的扫描根目录查找文件 |
| `[安装](guide.md#install)` | 检查 `guide.md` 是否存在，忽略章节名 |
| `[手册]: docs/guide.md` | 在引用定义所在行检查一次目标，即使文档中尚未使用它 |

默认读取 UTF-8 编码的 `.md` 和 `.markdown` 文件，跳过符号链接和 `.git`、`node_modules`、`.venv`、`build`、`dist` 等目录。链接中的 `%20` 等 URL 编码会在查找文件时解码。

解析器处理常见单行 Markdown 语法，跳过顶层围栏代码块、四空格或制表符缩进的行、单行行内代码、外部网址和纯页内锚点。HTML、跨行语法以及列表或引用块里的嵌套围栏超出解析范围。

## 自动检查

将这个项目放在仓库根目录并启用 GitHub Actions 后，每次推送或提交拉取请求都会运行单元测试，再运行一次仓库链接检查。发现失效引用时，对应的检查会失败。配置见 [检查工作流](.github/workflows/check.yml)。

命令退出码可用于其他持续集成系统。

| 退出码 | 含义 |
| --- | --- |
| `0` | 检查完成，所有已检查的路径均有效 |
| `1` | 发现失效或越出扫描根目录的路径 |
| `2` | 参数有误，或扫描期间出现读取错误 |

在本地运行[测试](tests/)：

```sh
python -m unittest discover -s tests -v
```
