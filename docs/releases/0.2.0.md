# mdpath 0.2.0

这个版本可以作为命令行工具安装。进入任意仓库运行 `mdpath .`，就能定位 Markdown 中指向已移动文件或图片的链接。需要 Python 3.10 或更新版本，运行时仅使用标准库。

```sh
python -m pip install https://github.com/kunzi4261-lang/mdpath/releases/download/v0.2.0/mdpath-0.2.0-py3-none-any.whl
mdpath .
```

- `mdpath . --github` 在 GitHub Actions 中为失效链接生成文件和行号标注。
- `mdpath . --json` 输出可供脚本使用的报告。原有的 `python mdpath.py .` 入口继续可用。
- 改进了路径中字符实体的解析，并修复了 Windows 在部分控制台编码下输出 Unicode 文件名时的错误。
